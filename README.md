# Mini Mario

A small Mario-style platform game built with Java Swing. All graphics are drawn in code; no image assets are required.

## Run

Requires Java 17 or newer.

```bash
./gradlew run
```

On Windows, use `gradlew.bat run`.

## Controls

- **A / D** or **← / →**: Move
- **Space**, **W**, or **↑**: Jump / start
- **P**: Pause
- **R**: Restart

Collect coins, stomp enemies, and reach the flag.
